# Auto Sales Analysis

## Project Overview
This project analyzes an automobile sales dataset using SQL and Power BI to uncover business insights and build an interactive dashboard.

# Business Questions Answered
- What is the total sales revenue?
- How many orders were placed?
- What is the average sales value?
- How many unique customers made purchases?
- Which product line generated the highest sales?
- Which customers generated the highest revenue?
- What is the distribution of order status?
- How do sales vary by deal size?
- Which countries generated the highest sales?
- What is the monthly sales trend?
  
## Tools Used
- MySQL
- Power BI
- Microsoft Excel

## Dashboard Insights
- Interactive filters by Year, Month, and Country
- KPI cards for Sales, Orders, Average Sales, and Customers
- Sales by Product Line
- Sales by Customer
- Sales by Country (Map)
- Orders by Status
- Sales by Deal Size
- Monthly Sales Trend
